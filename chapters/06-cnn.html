Convolutional Networks and Computer Vision

Convolutional networks started the deep learning revolution and taught the field how to build deep, trainable architectures. Today, vision Transformers and diffusion models have taken over much of vision, but the ideas here (locality, weight sharing, residual connections, pretraining then transfer) run through everything.

Why not just use an MLP on pixels?

A 224×224 colour image has 150,528 numbers. A dense layer with 4,096 outputs would need 617 million weights for the first layer alone, and it would have to learn separately that a cat in the top-left is the same as a cat in the bottom-right. Images have structure an MLP ignores:

  • Locality: nearby pixels are related.
  • Translation equivariance: a pattern means the same thing wherever it appears.

The convolution

A convolution slides a small filter (say 3×3) across the image, computing a dot product at every position. The same filter weights are reused everywhere (weight sharing). A layer has many filters, each producing a feature map that lights up where its pattern appears.

Early layers learn edges and colour blobs; middle layers learn textures and parts (eyes, wheels); late layers learn whole objects. This hierarchy of learned features is the core insight of deep learning.

Output size of a conv: (W − K + 2P) / S + 1, for input width W, kernel K, padding P, stride S.

import torch, torch.nn as nn

class SmallCNN(nn.Module):
    def __init__(self, n_classes=10):
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, padding=1), nn.BatchNorm2d(32), nn.ReLU(),
            nn.MaxPool2d(2),                                  # 32x32 -> 16x16
            nn.Conv2d(32, 64, 3, padding=1), nn.BatchNorm2d(64), nn.ReLU(),
            nn.MaxPool2d(2),                                  # 16x16 -> 8x8
            nn.Conv2d(64, 128, 3, padding=1), nn.BatchNorm2d(128), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),                          # -> 1x1
        )
        self.head = nn.Linear(128, n_classes)
    def forward(self, x):
        return self.head(self.features(x).flatten(1))

x = torch.randn(8, 3, 32, 32)          # CIFAR-10 sized batch
print(SmallCNN()(x).shape)             # torch.Size([8, 10])

The landmark architectures

1998 LeNet-5 Conv + pool + dense; trained with backprop
2012 AlexNet GPUs, ReLU, dropout, data augmentation
2014 VGG Deep stacks of 3×3 convs
2014 GoogLeNet / Inception Parallel filter sizes; 1×1 convs to cut compute
2015 ResNet Residual connections; 152 layers
2017 MobileNet Depthwise-separable convs for phones
2019 EfficientNet Scale depth, width, resolution together
2020 Vision Transformer (ViT) Split image into 16×16 patches; treat patches as tokens
2022 ConvNeXt Modernised CNN that matches ViTs

ResNet: the idea that made depth work

Before ResNet, adding layers beyond about 20 made accuracy worse, even on training data: the optimiser could not find good solutions. ResNet made each block learn a residual: output = x + F(x). If a layer is not useful, it can learn F(x)=0 and pass the input through unchanged.

class ResBlock(nn.Module):
    def __init__(self, c):
        super().__init__()
        self.body = nn.Sequential(
            nn.Conv2d(c, c, 3, padding=1), nn.BatchNorm2d(c), nn.ReLU(),
            nn.Conv2d(c, c, 3, padding=1), nn.BatchNorm2d(c))
    def forward(self, x):
        return torch.relu(x + self.body(x))     # the skip connection

Vision Transformers

ViT cuts an image into patches (e.g., 16×16 pixels), flattens each patch into a vector with a linear layer, adds position embeddings, and feeds the sequence into a standard Transformer. With enough data, ViTs beat CNNs, and they share infrastructure with language models, which is a large practical advantage. Most multimodal LLMs (Chapter 14) use a ViT-style image encoder.

Tasks beyond classification

  • Object detection: find boxes around objects (YOLO family, DETR).
  • Segmentation: label every pixel (U-Net, Mask R-CNN, Meta's Segment Anything/SAM series).
  • Depth, pose, tracking, OCR, and document understanding.
  • Generation: GANs, then diffusion models (Chapter 14).

Transfer learning: the business pattern

Training from scratch is expensive. Instead, take a model pretrained on a large dataset and fine-tune it on your small one. This pattern (pretrain once at great cost, adapt cheaply many times) is exactly the economics of foundation models.

import torchvision
model = torchvision.models.resnet50(weights="IMAGENET1K_V2")
for p in model.parameters():
    p.requires_grad = False                    # freeze the backbone
model.fc = nn.Linear(model.fc.in_features, 5)  # new head for 5 defect types
# train only model.fc on a few hundred labelled images

Project: Visual defect detection for a factory line

Business problem: a manufacturer inspects parts by hand; inspectors miss defects late in shifts, and throughput is capped.

  1. Use the MVTec AD dataset (public industrial-defect images).
  2. Fine-tune a pretrained ResNet or a small ViT; compare with a zero-shot vision-language model prompted with "Is this part defective?".
  3. Export to ONNX, then measure latency on CPU and on a GPU with TensorRT.
  4. Report: recall on defects at a fixed false-alarm rate, and images per second per dollar. The line runs at 5 parts per second; can you keep up on a $300 edge device?
