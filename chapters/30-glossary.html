Glossary

Quick definitions of the terms used throughout the book, with the chapter where each is explained in depth.

Term Meaning Ch.
Activation Intermediate output of a layer; must be stored for the backward pass 4
Activation checkpointing Discard activations and recompute them during backward to save memory 4, 17
AdamW Adaptive optimizer with decoupled weight decay; the LLM default 5
Agent A model running in a loop that calls tools and acts toward a goal 22
All-reduce / all-gather / reduce-scatter / all-to-all Collective communication operations across GPUs 17
Arithmetic intensity FLOPs per byte of memory moved; decides compute- vs memory-bound 15
Attention Mechanism where each token takes a weighted mix of other tokens' values 7, 9
AWQ / GPTQ 4-bit weight quantization methods 19
Backpropagation Chain-rule algorithm computing all gradients in one backward sweep 4
BF16 16-bit float with FP32's range; standard training format 2
BM25 Classic keyword relevance scoring for search 21
BPE Byte-pair encoding tokenizer 8
Chinchilla scaling Compute-optimal training uses ~20 tokens per parameter 10
Continuous batching Adding and removing sequences from a batch at every decode step 19
Context parallelism Splitting a long sequence across GPUs for attention 17
CUDA NVIDIA's GPU programming platform 16
CUDA graphs Record and replay kernel launches to remove CPU overhead 16
Decode Generating output one token at a time; memory-bandwidth-bound 19
Diffusion model Generative model that learns to reverse a noising process 14
Disaggregated serving Running prefill and decode on separate GPU pools 19
Distillation Training a small student model on a large teacher's outputs 12
DPO Direct Preference Optimization; preference tuning without RL 12
Embedding A learned vector representing a token, text, image or item 8
Expert parallelism Placing MoE experts on different GPUs 17
FlashAttention IO-aware attention kernel that never materialises the full score matrix 16
FLOPs Floating-point operations (FLOP/s = per second) 2
FP8 / FP4 / NVFP4 / MXFP4 Low-precision number formats with block scaling 2, 16
FSDP / ZeRO Sharding weights, gradients and optimizer state across data-parallel GPUs 17
GEMM General matrix multiply; the core operation of deep learning 2, 16
Goodput Useful throughput: training progress or requests that meet SLOs 10, 19
GQA / MQA / MLA Attention variants that shrink the KV cache 9
GRPO Group Relative Policy Optimization; RL without a value network 12
Hallucination Fluent but false or unsupported model output 21
HBM High-bandwidth memory stacked next to the GPU die 15
HNSW Graph-based approximate nearest-neighbour index 21
KV cache Stored keys and values of past tokens, reused during decoding 9, 19
LLM-as-judge Using a model to grade outputs against a rubric 23
LoRA / QLoRA Low-rank adapters for efficient fine-tuning (QLoRA: on a 4-bit base) 18
MCP Model Context Protocol; standard for connecting models to tools and data 22
MFU Model FLOPs utilisation: useful FLOP/s ÷ hardware peak 10, 17
MoE Mixture of experts; sparse layers where each token uses a few experts 11
NCCL NVIDIA's collective communication library 17
NVLink / NVSwitch NVIDIA's high-bandwidth GPU-to-GPU interconnect 15
PagedAttention Storing the KV cache in fixed-size blocks, like virtual memory 19
Perplexity exp(average cross-entropy); lower is better 2
Pipeline parallelism Splitting layers across GPUs and streaming micro-batches 17
Prefill Processing the prompt in parallel; compute-bound 19
Prefix / prompt caching Reusing KV cache for shared prompt prefixes 19
Prompt injection Malicious instructions in content an AI system reads 22, 27
PUE Power usage effectiveness of a data center 25
Quantization Representing weights/activations with fewer bits 19
RAG Retrieval-augmented generation 21
Reranker Cross-encoder that rescores retrieved candidates 21
Residual connection x + f(x); lets gradients flow through deep networks 5, 6
RLHF / RLAIF / RLVR RL from human feedback / AI feedback / verifiable rewards 12
RMSNorm Normalisation by root-mean-square; used in modern LLMs 5
Roofline model Performance bound from peak compute and memory bandwidth 15
RoPE Rotary position embedding 8, 9
Scaling laws Power-law relations between loss and compute, data, parameters 10
SFT Supervised fine-tuning on demonstrations 12
Softmax Converts scores into a probability distribution 2
Sparse autoencoder Tool that decomposes activations into interpretable features 27
Speculative decoding Draft-and-verify decoding that emits several tokens per big-model step 19
SSM / linear attention Recurrent-style layers with fixed-size state (Mamba, Gated DeltaNet) 11
SwiGLU Gated feed-forward activation used in modern LLMs 4, 9
Tensor Core GPU unit that performs small matrix multiplies in one instruction 15
Tensor parallelism Splitting each weight matrix across GPUs 17
Test-time compute Spending more inference tokens (thinking, sampling) for better answers 13
Token Unit of text a model processes (a subword) 8
TPOT / TTFT Time per output token / time to first token 19
Triton Python-based language for writing GPU kernels 16
vLLM / SGLang / TensorRT-LLM Leading LLM serving engines 19
