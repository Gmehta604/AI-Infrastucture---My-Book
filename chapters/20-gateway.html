LLM Gateways, Routing and Cost Engineering

Most companies don't run one model; they call several providers and a few self-hosted models from dozens of internal teams. The LLM gateway is the control point that makes this reliable, observable and affordable. It is one of the most practical systems you can build.

The problems a gateway solves

  • Runaway cost: nobody knows which team or feature spends what.
  • Outages and rate limits: a provider has an incident; your product goes down with it.
  • Latency spikes: p99 latency from APIs can be 10× the median.
  • Vendor lock-in: every team hard-codes a different SDK.
  • Compliance: PII leaving the company, missing audit logs.
  • Wasted spend: the same questions answered repeatedly; frontier models used for trivial tasks.

Architecture

Routing strategies

Strategy How Example
Static by feature Config maps feature → model Autocomplete uses a small model; legal review uses frontier
Cascade Try cheap model; escalate if confidence is low or a check fails Small model answers, validator checks JSON, escalate on failure
Learned router Classifier predicts which model will succeed RouteLLM-style routers trained on preference data
Latency/cost-aware Pick the provider with the best current p95 or price Live health scores per endpoint
Effort routing Choose reasoning effort / thinking budget per query Chapter 13 project

Caching

  • Exact cache: hash of (model, messages, parameters) → response. Safe, simple, good for repeated system tasks.
  • Semantic cache: embed the query; if a previous query is within a similarity threshold, reuse its answer. Big savings for FAQ-style traffic, but risky: "cancel my order" and "don't cancel my order" can be close in embedding space. Use high thresholds, scope by user/tenant, and never semantic-cache personalised or action-taking requests.
  • Provider prompt caching: structure prompts so the long stable prefix is identical across calls, and the provider discounts it (Chapter 19).

A working gateway in about 150 lines

# gateway.py  -- pip install fastapi uvicorn httpx redis numpy sentence-transformers
import hashlib, json, time, asyncio, os
import httpx, numpy as np, redis
from fastapi import FastAPI, HTTPException, Header
from pydantic import BaseModel
from sentence_transformers import SentenceTransformer

app = FastAPI()
r = redis.Redis(decode_responses=True)
embedder = SentenceTransformer("BAAI/bge-small-en-v1.5")

# price per 1M tokens (input, output) -- fill in current prices
PROVIDERS = {
    "small": {"url": "http://vllm-small:8000/v1/chat/completions", "model": "Qwen/Qwen2.5-7B-Instruct",
              "key": None, "price": (0.05, 0.10)},
    "frontier": {"url": "https://api.openai.com/v1/chat/completions", "model": "gpt-5.5",
                 "key": os.getenv("OPENAI_API_KEY"), "price": (1.25, 10.0)},
}
FALLBACKS = {"small": ["small", "frontier"], "frontier": ["frontier", "small"]}
TEAM_BUDGET_USD = {"support": 500.0, "search": 2000.0}

class ChatReq(BaseModel):
    messages: list[dict]
    tier: str | None = None          # caller may force a tier
    max_tokens: int = 512
    temperature: float = 0.0

def route(req: ChatReq) -> str:
    if req.tier:
        return req.tier
    text = req.messages[-1]["content"]
    hard = len(text) > 2000 or any(w in text.lower() for w in ["prove", "analyze", "step by step", "code"])
    return "frontier" if hard else "small"

def exact_key(req, tier):
    blob = json.dumps({"m": req.messages, "t": tier, "temp": req.temperature}, sort_keys=True)
    return "exact:" + hashlib.sha256(blob.encode()).hexdigest()

def semantic_lookup(text, threshold=0.95):
    q = embedder.encode(text, normalize_embeddings=True)
    for key in r.scan_iter("sem:*"):                     # demo only: use a vector index in production
        item = json.loads(r.get(key))
        if float(np.dot(q, np.array(item["emb"]))) >= threshold:
            return item["resp"]
    return None

def semantic_store(text, resp):
    emb = embedder.encode(text, normalize_embeddings=True).tolist()
    key = "sem:" + hashlib.sha1(text.encode()).hexdigest()
    r.set(key, json.dumps({"emb": emb, "resp": resp}), ex=86400)

class Breaker:                                            # simple circuit breaker per provider
    def __init__(self): self.fail, self.open_until = {}, {}
    def ok(self, p): return time.time() > self.open_until.get(p, 0)
    def record(self, p, success):
        if success: self.fail[p] = 0; return
        self.fail[p] = self.fail.get(p, 0) + 1
        if self.fail[p] >= 3: self.open_until[p] = time.time() + 30
breaker = Breaker()

async def call(p, req):
    cfg = PROVIDERS[p]
    headers = {"Authorization": f"Bearer {cfg['key']}"} if cfg["key"] else {}
    body = {"model": cfg["model"], "messages": req.messages,
            "max_tokens": req.max_tokens, "temperature": req.temperature}
    async with httpx.AsyncClient(timeout=30) as c:
        resp = await c.post(cfg["url"], json=body, headers=headers)
        resp.raise_for_status()
        return resp.json()

def cost(p, usage):
    pin, pout = PROVIDERS[p]["price"]
    return usage.get("prompt_tokens", 0) / 1e6 * pin + usage.get("completion_tokens", 0) / 1e6 * pout

@app.post("/v1/chat")
async def chat(req: ChatReq, x_team: str = Header(...)):
    spent = float(r.get(f"spend:{x_team}") or 0)
    if spent >= TEAM_BUDGET_USD.get(x_team, 100):
        raise HTTPException(429, f"Monthly budget reached for team '{x_team}'")

    tier = route(req)
    ek = exact_key(req, tier)
    if (hit := r.get(ek)):
        return {"cached": "exact", **json.loads(hit)}
    last = req.messages[-1]["content"]
    if req.temperature == 0 and len(req.messages) == 1 and (hit := semantic_lookup(last)):
        return {"cached": "semantic", **hit}

    errors = []
    for p in FALLBACKS[tier]:
        if not breaker.ok(p):
            errors.append(f"{p}: circuit open"); continue
        for attempt in range(2):                          # retry with backoff
            t0 = time.perf_counter()
            try:
                out = await call(p, req)
                breaker.record(p, True)
                usd = cost(p, out.get("usage", {}))
                r.incrbyfloat(f"spend:{x_team}", usd)
                result = {"provider": p, "latency_ms": int((time.perf_counter() - t0) * 1000),
                          "cost_usd": round(usd, 6), "response": out["choices"][0]["message"]["content"]}
                r.set(ek, json.dumps(result), ex=3600)
                if req.temperature == 0 and len(req.messages) == 1:
                    semantic_store(last, result)
                return {"cached": None, **result}
            except Exception as e:
                breaker.record(p, False)
                errors.append(f"{p}#{attempt}: {e}")
                await asyncio.sleep(0.5 * 2 ** attempt)
    raise HTTPException(503, {"error": "all providers failed", "details": errors})

Production gateways add streaming passthrough, a proper vector index for the semantic cache, OpenTelemetry tracing, async logging to a warehouse, per-key rate limits (token bucket in Redis), and admin dashboards. Open-source and commercial options include LiteLLM, Portkey, Kong AI Gateway, Cloudflare AI Gateway, OpenRouter (a hosted multi-provider router), Envoy AI Gateway, and cloud-native offerings.

Cost engineering checklist

  1. Measure first: tokens in/out, cost and latency per feature, per team, per customer.
  2. Right-size models: most traffic doesn't need the frontier model.
  3. Trim prompts: remove redundant instructions and oversized RAG context; long system prompts are paid on every call (unless cached).
  4. Cap output: max_tokens, concise-style instructions, structured output instead of prose.
  5. Cache: exact, semantic (carefully), and provider prompt caching.
  6. Batch APIs: offline jobs via providers' batch endpoints at roughly 50% discount.
  7. Self-host the high-volume, narrow tasks (Chapter 18) once volume crosses break-even.
  8. Set budgets and alerts per team; agents in loops can burn thousands of dollars overnight.

Project 2: "Latency spikes and runaway costs"

Business problem: a SaaS company's AI features call one provider directly. Last month an outage took the product down for two hours, and the bill doubled without anyone knowing why.

  1. Build the gateway above; add streaming, Prometheus metrics (requests, tokens, cost, latency histograms per provider and team) and a Grafana dashboard.
  2. Replay a realistic traffic log (e.g., a public chat dataset such as LMSYS-Chat-1M or WildChat).
  3. Measure: cache hit rate, % routed to the small model, quality on a sample judged by a strong model, total cost vs. "everything to frontier."
  4. Chaos test: kill one provider mid-test and show zero failed user requests.
