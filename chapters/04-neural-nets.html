Neural Networks and Backpropagation

A neural network is a stack of simple functions whose parameters are learned by gradient descent. In this chapter you will build one from scratch, including the automatic differentiation engine that PyTorch hides from you.

The neuron

A neuron takes inputs, computes a weighted sum plus a bias, and passes it through a nonlinear activation function:

output = activation(w₁x₁ + w₂x₂ + … + wₙxₙ + b)

Why the nonlinearity matters

Stacking linear functions gives another linear function: W₂(W₁x) = (W₂W₁)x. Without activations, a 100-layer network is no more powerful than one layer. The nonlinearity is what lets depth build complex functions. The universal approximation theorem says a network with one hidden layer and enough neurons can approximate any continuous function, but depth makes it far more efficient.

Activation Formula Notes
Sigmoid 1/(1+e⁻ˣ) Saturates, so gradients vanish; now used for gates
Tanh (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) Zero-centred sigmoid; used in LSTMs
ReLU max(0, x) Cheap, no saturation for x>0; the 2012–2019 default
GELU x·Φ(x) Smooth ReLU; GPT-2, BERT
SiLU / Swish x·sigmoid(x) Used inside SwiGLU
SwiGLU (xW)·SiLU(xV) The standard in modern LLM feed-forward layers (Llama, Qwen, DeepSeek)

A multi-layer perceptron (MLP)

Layers of neurons connected to every neuron in the next layer form an MLP (also called a fully-connected or dense network). In matrix form, one layer is h = f(Wx + b). The feed-forward block inside every Transformer is an MLP.

Backpropagation, step by step

Training needs the gradient of the loss with respect to every weight. Computing each separately would be hopelessly slow. Backpropagation does it in one backward sweep by reusing intermediate results, applying the chain rule from the output back to the input.

Take a tiny example: L = (w·x + b − y)² with x=2, w=3, b=1, y=10.

Forward pass:

z = w·x = 6 p = z + b = 7 e = p − y = −3 L = e² = 9

Backward pass (each step multiplies by a local derivative):

dL/de = 2e = −6 dL/dp = dL/de · 1 = −6 dL/db = dL/dp · 1 = −6 dL/dz = dL/dp · 1 = −6 dL/dw = dL/dz · x = −12

Both gradients are negative, so increasing w and b reduces the loss, which is correct: we predicted 7 but wanted 10.

Build an autograd engine (micrograd-style)

This is the single best exercise for understanding deep learning frameworks. Every PyTorch tensor secretly does what this Value class does: record how it was made, then walk the graph backwards.

import math, random

class Value:
    def __init__(self, data, parents=(), op=""):
        self.data, self.grad = data, 0.0
        self._parents, self._op = parents, op
        self._backward = lambda: None

    def __add__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data + other.data, (self, other), "+")
        def _backward():
            self.grad += out.grad
            other.grad += out.grad
        out._backward = _backward
        return out

    def __mul__(self, other):
        other = other if isinstance(other, Value) else Value(other)
        out = Value(self.data * other.data, (self, other), "*")
        def _backward():
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = _backward
        return out

    def tanh(self):
        t = math.tanh(self.data)
        out = Value(t, (self,), "tanh")
        def _backward():
            self.grad += (1 - t * t) * out.grad
        out._backward = _backward
        return out

    def __neg__(self): return self * -1
    def __sub__(self, other): return self + (-other)
    def __pow__(self, k):
        out = Value(self.data ** k, (self,), f"**{k}")
        def _backward():
            self.grad += k * self.data ** (k - 1) * out.grad
        out._backward = _backward
        return out
    __radd__ = __add__
    __rmul__ = __mul__

    def backward(self):
        order, seen = [], set()
        def build(v):                      # topological sort
            if v not in seen:
                seen.add(v)
                for p in v._parents: build(p)
                order.append(v)
        build(self)
        self.grad = 1.0
        for v in reversed(order):
            v._backward()

class Neuron:
    def __init__(self, n_in):
        self.w = [Value(random.uniform(-1, 1)) for _ in range(n_in)]
        self.b = Value(0.0)
    def __call__(self, x):
        return sum((wi * xi for wi, xi in zip(self.w, x)), self.b).tanh()
    def params(self): return self.w + [self.b]

class MLP:
    def __init__(self, sizes):
        self.layers = [[Neuron(sizes[i]) for _ in range(sizes[i + 1])]
                       for i in range(len(sizes) - 1)]
    def __call__(self, x):
        for layer in self.layers:
            x = [n(x) for n in layer]
        return x[0] if len(x) == 1 else x
    def params(self): return [p for layer in self.layers for n in layer for p in n.params()]

# Learn XOR, the problem that killed the perceptron in 1969
xs = [[0, 0], [0, 1], [1, 0], [1, 1]]
ys = [-1, 1, 1, -1]
net = MLP([2, 4, 1])
for step in range(500):
    preds = [net(x) for x in xs]
    loss = sum((p - y) ** 2 for p, y in zip(preds, ys))
    for p in net.params(): p.grad = 0.0
    loss.backward()
    for p in net.params(): p.data -= 0.05 * p.grad
print([round(net(x).data, 2) for x in xs])   # ≈ [-1, 1, 1, -1]

Key idea. The backward pass costs roughly twice the forward pass, because for each matmul you compute gradients with respect to both the input and the weights. Forward (2N) + backward (4N) = the 6N FLOPs per token training rule from Chapter 2.

The same network in PyTorch

import torch, torch.nn as nn

X = torch.tensor([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
y = torch.tensor([[0.], [1.], [1.], [0.]])

model = nn.Sequential(nn.Linear(2, 8), nn.ReLU(), nn.Linear(8, 1))
opt = torch.optim.Adam(model.parameters(), lr=0.05)
loss_fn = nn.BCEWithLogitsLoss()

for step in range(500):
    opt.zero_grad()              # clear old gradients
    loss = loss_fn(model(X), y)  # forward
    loss.backward()              # backward (autograd)
    opt.step()                   # update
print(torch.sigmoid(model(X)).round().squeeze())

Those five lines inside the loop (zero_grad, forward, loss, backward, step) are the heartbeat of all deep learning, from XOR to a trillion-parameter model. Everything in distributed training (Chapter 17) is about running this loop across thousands of GPUs.

What the forward pass stores: activations

To compute gradients, the backward pass needs intermediate values from the forward pass (like x in dL/dw = dL/dz · x). These activations must be kept in memory until the backward pass uses them. For large models, activation memory often exceeds weight memory. Activation checkpointing (also called gradient checkpointing) discards some activations and recomputes them during backward, trading about 30% more compute for much less memory. You will use it in Chapters 17 and 18.
