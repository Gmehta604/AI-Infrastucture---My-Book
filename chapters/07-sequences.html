Sequence Models: From RNNs to Attention

Language, audio, time series and code are sequences. This chapter traces how models learned to handle them, from recurrent networks to the attention mechanism, and explains exactly which bottleneck the Transformer removed.

The problem

A sequence model must handle inputs of varying length and let earlier elements influence later ones. "The keys to the cabinet are on the table": the verb must agree with "keys", four words back.

Recurrent neural networks (RNNs)

An RNN reads one token at a time and carries a hidden state h forward, a running summary of everything seen so far:

hₜ = tanh(W_h · hₜ₋₁ + W_x · xₜ + b) yₜ = W_y · hₜ
import torch, torch.nn as nn

class CharRNN(nn.Module):
    def __init__(self, vocab, hidden=256):
        super().__init__()
        self.emb = nn.Embedding(vocab, hidden)
        self.rnn = nn.LSTM(hidden, hidden, num_layers=2, batch_first=True)
        self.out = nn.Linear(hidden, vocab)
    def forward(self, idx, state=None):
        h, state = self.rnn(self.emb(idx), state)
        return self.out(h), state

Two fatal problems

  1. Vanishing and exploding gradients. Backpropagating through 100 time steps multiplies 100 Jacobians together. The product shrinks to zero or blows up, so the network cannot learn long-range dependencies.
  2. Sequential computation. Step t needs step t−1. You cannot parallelise across the sequence, so GPUs sit mostly idle. This is an infrastructure problem, and it is the one that ultimately killed RNNs.

LSTMs and GRUs

The LSTM (1997) adds a separate cell state with gates (small sigmoid layers) that decide what to forget, what to write, and what to output. Because the cell state is updated additively, gradients flow across many steps. The GRU (2014) is a simpler variant. LSTMs powered Google Translate, Siri and Alexa speech recognition in the 2010s.

Sequence-to-sequence and the bottleneck

For translation, an encoder RNN reads the source sentence into a final hidden state, and a decoder RNN generates the target from it. The problem: the whole sentence must squeeze through one fixed-size vector.

Attention: let the decoder look back

Bahdanau et al. (2014) let the decoder, at each step, compute a weighted average of all encoder states, with weights based on relevance. To output "chat", it attends mostly to "cat".

The mechanism in three steps:

  1. Score: compare the current decoder state (the query) with every encoder state (the keys).
  2. Normalise: softmax the scores into weights that sum to 1.
  3. Blend: take the weighted sum of encoder states (the values).
import torch.nn.functional as F

def attention(query, keys, values):
    # query: (d,)   keys, values: (T, d)
    scores = keys @ query                 # (T,) dot-product relevance
    weights = F.softmax(scores, dim=0)    # (T,) sums to 1
    return weights @ values               # (d,) weighted blend

That function is the seed of the Transformer.

"Attention Is All You Need"

In 2017, Vaswani et al. asked: if attention is doing the useful work, why keep the recurrence at all? The Transformer uses self-attention, where every token attends to every other token in the same sequence, and processes all positions in parallel.

RNN / LSTM Transformer
Path length between distant tokens O(n) steps O(1): direct attention
Parallel across sequence (training) No Yes
Compute per layer O(n·d²) O(n²·d + n·d²)
Memory of the past at inference Fixed-size state Grows with context (KV cache)
GPU utilisation Poor Excellent

Note the last two rows. The Transformer's weakness is the mirror image of the RNN's: attention cost grows quadratically with sequence length, and at inference it keeps a cache that grows linearly. That trade-off is why modern research has partially brought recurrence back in the form of state-space models and linear attention (Mamba, Gated DeltaNet), mixed with attention in hybrid architectures (Chapter 11).

Other sequence domains

  • Speech: Whisper (2022) is an encoder-decoder Transformer on audio spectrograms.
  • Time series: gradient boosting and simple models remain strong; foundation models (TimesFM, Chronos) are emerging.
  • Biology: proteins and DNA are sequences; AlphaFold 2 (2020) and protein language models use attention.
