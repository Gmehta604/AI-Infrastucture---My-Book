How to use this book

Read in order the first time; every chapter builds on the last. Type the code yourself rather than copying it. Chapters tied to a real business problem end with a Build it project you can put in a portfolio. Deep dives (marked ↳) go further on a single chapter, with runnable scripts in the code/ folder. Mark chapters as read to track your progress in this browser.
